## AG-UI protocol

| Fact | Source |
| --- | --- |
| AG-UI is "an open, lightweight, event-based protocol that standardizes how AI agents connect to user-facing applications", maintained by the `ag-ui-protocol` organization, MIT license | [Introduction](https://docs.ag-ui.com/introduction.md), [repository](https://github.com/ag-ui-protocol/ag-ui) |
| The specification is "Draft — not yet ratified" (1.0 draft); nothing is covered by a compatibility promise until a version is frozen | [Spec index](https://docs.ag-ui.com/spec/draft/index.md), [versioning](https://docs.ag-ui.com/spec/draft/basic/versioning.md) |
| The HTTP transport is a `POST` of a JSON `RunAgentInput` answered by `text/event-stream`; errors before the stream are HTTP statuses, errors during it are `RUN_ERROR`; no stream resumption | [HTTP + SSE transport](https://docs.ag-ui.com/spec/draft/basic/transports/http-sse.md) |
| Events: `RUN_STARTED`/`RUN_FINISHED`/`RUN_ERROR`, `STEP_*`, `TEXT_MESSAGE_START`/`_CONTENT`/`_END`/`_CHUNK`, `TOOL_CALL_START`/`_ARGS`/`_END`/`_RESULT`/`_CHUNK`, `STATE_SNAPSHOT`, `STATE_DELTA` (JSON Patch), `MESSAGES_SNAPSHOT`, `RAW`, `CUSTOM`. New in the draft: `ACTIVITY_SNAPSHOT`/`ACTIVITY_DELTA`, `REASONING_*` (replacing the deprecated `THINKING_*`), `SUBAGENT_*`, and an `outcome` (success or interrupt) on `RUN_FINISHED` | [Events](https://docs.ag-ui.com/concepts/events.md), [spec changelog](https://docs.ag-ui.com/spec/draft/changelog.md) |
| `RunAgentInput` carries `threadId`, `runId`, `parentRunId?`, `state?`, `messages`, `tools`, `context`, `forwardedProps`, `resume?`; message roles are `developer`, `system`, `assistant`, `user`, `tool`, `activity`, `reasoning` | [JS core types](https://docs.ag-ui.com/sdk/js/core/types.md) |
| Frontend tools are declared by the client in `RunAgentInput.tools`; the client executes them and sends the result back as a tool message | [Tools](https://docs.ag-ui.com/concepts/tools.md) |
| Interrupts finish a run with `outcome: { type: "interrupt", interrupts[] }` and are answered with `RunAgentInput.resume` on the same thread | [Interrupts](https://docs.ag-ui.com/concepts/interrupts.md) |
| "AG-UI is not a generative UI specification"; activity messages are "rendering material for the consumer" and must be stripped from the messages a client sends back | [Generative UI specs](https://docs.ag-ui.com/concepts/generative-ui-specs.md), [activity events](https://docs.ag-ui.com/spec/draft/events/activity.md) |
| `@ag-ui/client` **0.0.59** (MIT) depends on `rxjs` **7.8.1 exactly**, `zod ^3.22.4`, `uuid`, `fast-json-patch`, and `@ag-ui/core`/`encoder`/`proto` 0.0.59 | [npm manifest](https://registry.npmjs.org/@ag-ui/client/latest) (re-checked 2026-09-13) |
| `AbstractAgent` defaults `threadId` to a client-generated UUID, builds `RunAgentInput.messages` from its **full** `messages` history (activity messages removed), and defaults `tools`/`context` to `[]` and `forwardedProps` to `{}` | [agent.ts](https://github.com/ag-ui-protocol/ag-ui/blob/main/sdks/typescript/packages/client/src/agent/agent.ts) |
| The default `connect()` throws `AGUIConnectNotImplementedError`; `connectAgent()` runs the connect stream through `transformChunks` → `verifyEvents` → apply, and a `MESSAGES_SNAPSHOT` replaces `messages` | [agent.ts](https://github.com/ag-ui-protocol/ag-ui/blob/main/sdks/typescript/packages/client/src/agent/agent.ts), [published build](https://unpkg.com/@ag-ui/client@0.0.59/dist/index.mjs) |
| `HttpAgent({ url, headers, fetch })`: `run()` calls `this.fetch(this.url, this.requestInit(input))`; a non-2xx response becomes `Error("HTTP <status>: …")` with `.status` and `.payload`; `requestInit` sends `Accept: text/event-stream`; `clone()` keeps `url`, `headers`, `fetch` and the subclass prototype; there is no per-run headers parameter | [http.ts](https://github.com/ag-ui-protocol/ag-ui/blob/main/sdks/typescript/packages/client/src/agent/http.ts), [published types](https://unpkg.com/@ag-ui/client@0.0.59/dist/index.d.ts), [HttpAgent docs](https://docs.ag-ui.com/sdk/js/client/http-agent.md) |
| Client middleware (`agent.use(...)`) runs in `runAgent()`; "`connectAgent()` currently calls `connect()` directly and does not run middleware" | [Middleware](https://docs.ag-ui.com/sdk/js/client/middleware.md) |
